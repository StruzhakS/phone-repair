### 📊 Dashboard/Dashboard.jsx
**Аналітична панель з 6 показниками**

**Показники:**
1. **Вартість телефонів** (синій)
   - Сума всіх куплених телефонів

2. **Вартість запчастин** (помаранчевий)
   - Сума всіх купленних комплектуючих

3. **Всього інвестовано** (червоний)
   - Сума телефонів + запчастини

4. **Продано на** (зелений)
   - Сума реалізацій від проданих телефонів

5. **Чистий прибуток** (динамічний)
   - Прибуток від проданих телефонів
   - Зелений якщо позитивний, червоний якщо негативний

6. **Можливий прибуток** (фіолетовий)
   - Очікуваний прибуток від непроданих телефонів

**Props:**
- `phones` (array) - масив телефонів

**Розрахунки:**
```javascript
totalPricePhones = sum(Price)
totalPriceDetails = sum(Detailprice)
netProfit = totalSoldValue - (totalPricePhones + totalPriceDetails)
possibleProfit = sum(Sold_for - Price - Detailprice) для непроданих
```

### 📱 PhonesList/PhonesList.jsx
**Таблиця з усіма телефонами**

**Колонки таблиці:**
1. **ID** - ID телефону (фіолетовий, моноширинний)
2. **Модель** - Назва моделі з іконкою примітки
3. **Ціна телефону** - Вартість телефону (₴)
4. **Ціна запчастин** - Вартість комплектуючих (₴)
5. **Ціна продажу** - Ціна за яку продано (₴)
6. **Прибуток** - Динамічний розрахунок (зелений/червоний)
7. **Статус** - Продано/Не продано (клікабельно)
8. **Дії** - Редагування/Видалення

**Функціональність:**
- Клік на статус = зміна статусу
- Клік ✏️ = відкрити редагування
- Клік 🗑️ = видалення з підтвердженням
- Пустий стан з повідомленням

**Props:**
- `phones` (array) - масив телефонів для відображення

**State:**
- `editingPhone` - поточний телефон для редагування

**Резюме таблиці:**
- 📊 Всього телефонів
- ✅ Продано
- 🔄 Непродано

## 🔄 Redux

### Store.js
Конфігурація Redux store

```javascript
configureStore({
  reducer: {
    phone: phoneReducer
  }
})
```

---

### PhonesSlice.js
Redux слайс для управління телефонами

**State:**
- `phones` - масив телефонів
- `filter` - поточний фільтр (all/sold/not_sold)
- `filterById` - фільтр за ID/моделлю
- `loading` - статус завантаження
- `error` - помилка

**Reducers:**
- `filterPhones(state, action)` - встановити фільтр по статусу
- `filterPhonesById(state, action)` - встановити фільтр по ID

**Extra Reducers:**
- `getallPhonesOperation` - завантаження телефонів
- `addPhoneOperation` - додавання телефону
- `deletePhoneOperation` - видалення телефону
- `updatePhoneOperation` - редагування телефону
- `updatePhoneStatusOperation` - змінення статусу

---

### Operations.js
Async операції (thunks)

**Операції:**
1. `getallPhonesOperation()` - GET всі телефони
2. `addPhoneOperation(phone)` - POST новий телефон
3. `deletePhoneOperation(id)` - DELETE телефон
4. `updatePhoneOperation(changeData)` - PUT оновлення
5. `updatePhoneStatusOperation(statusData)` - PUT змінення статусу

---

### PhonesApi.js
API запити (Axios)

**Функції:**
- `getPhonesApi()` - GET /Phones
- `getPhoneByIdApi(id)` - GET /Phones/:id
- `addPhoneApi(user)` - POST /Phones
- `deletePhoneApi(id)` - DELETE /Phones/:id
- `updateModelApi(changeData)` - PUT /Phones/:id
- `updateStatusPhoneApi({id, check})` - PUT /Phones/:id (зміна isSold)

## 🎯 Лайфцикл

1. **Завантаження**
   ```
   App monuted
   → getallPhonesOperation()
   → API запит
   → phones state оновлюється
   → Компоненти перерендерюються
   ```

2. **Фільтрація**
   ```
   User вибирає фільтр
   → dispatch(filterPhones(value))
   → state.filter оновлюється
   → App re-renders з новими phones
   ```

3. **Додавання**
   ```
   User натискає "Додати"
   → Модаль відкривається
   → User заповнює форму
   → dispatch(addPhoneOperation(data))
   → API POST запит
   → phones array оновлюється
   → Модаль закривається
   ```

4. **Редагування**
   ```
   User натискає ✏️
   → EditPhoneModal відкривається
   → User змінює дані
   → dispatch(updatePhoneOperation(data))
   → API PUT запит
   → phones array оновлюється
   → Модаль закривається
   ```

5. **Видалення**
   ```
   User натискає 🗑️
   → Показується підтвердження
   → User підтверджує
   → dispatch(deletePhoneOperation(id))
   → API DELETE запит
   → phones array оновлюється
   ```
