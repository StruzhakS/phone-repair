# 📱 Phone Repair Manager

Сучасний веб-застосунок для управління ремонтом та продажем телефонів зі стильним інтерфейсом та потужною аналітикою.

## ✨ Нові функції

### 🎨 Сучасний дизайн
- **Красивий градієнтний інтерфейс** - мінімалістичний дизайн з плавними переходами
- **Адаптивний макет** - ідеально працює на мобільних пристроях та десктопах
- **Темна схема кольорів** - зручна палітра для довготривалого використання
- **Анімації та ефекти** - гладкі переходи та взаємодія

### 📊 Розширена аналітика (Dashboard)
Новий розділ зі статистикою:
- 📱 **Вартість телефонів** - сума всіх куплених телефонів
- 🔧 **Вартість запчастин** - витрати на комплектуючі
- 💸 **Всього інвестовано** - загальні витрати
- 💰 **Продано на** - сума реалізацій
- 📈 **Чистий прибуток** - реальний прибуток з проданих телефонів
- 🎯 **Можливий прибуток** - очікуваний прибуток від непроданих телефонів

### 🔍 Покращена таблиця
- ✅ Колоновіль стану (Продано/Не продано) з кольоровими бейджами
- 🎨 Кольорові показники прибутку (зелений/червоний)
- 🖱️ Один клік для змінення статусу телефону
- ✏️ Вбудована редакція прямо з таблиці
- 🗑️ Швидке видалення записів

### 🔧 Розширена фільтрація та сортування
- **Фільтри**:
  - 📱 Всі телефони
  - ✅ Тільки продані
  - 🔄 Тільки непродані

- **Сортування**:
  - 📅 За датою додавання
  - 💰 За ціною (зростання/спадання)
  - 📈 За прибутком (мін/макс)

- **Пошук**:
  - Пошук по ID телефону
  - Пошук по моделі (iPhone, Samsung тощо)

### ➕ Улучшений модальні вікна
- **Додавання телефону**: інтуїтивна форма з всіма необхідними полями
- **Редагування телефону**: відредагуйте будь-який запис не залишаючи таблицю
- 🎨 Стильний дизайн з зручною навігацією

### 🏆 Інші вдосконалення
- **Резюме таблиці** - швидкий вид на статистику (кількість всіх, проданих, непроданих)
- **Emoji-іконки** - просто розпізнавання функцій
- **Динамічні розрахунки** - всі цифри обчислюються в реальному часі
- **Сохранение даних** - всі ваші дані залишаються в MockAPI

## 🚀 Встановлення та запуск

### Вимоги
- Node.js (LTS версія)
- npm

### Кроки встановлення

1. **Клонуйте репозиторій**
   ```bash
   git clone <repository-url>
   cd phone-repair
   ```

2. **Встановіть залежності**
   ```bash
   npm install
   ```

3. **Запустіть проект**
   ```bash
   npm start
   ```

4. **Відкрийте браузер**
   Перейдіть на [http://localhost:3000](http://localhost:3000)

## 🎯 Основні функції

### Управління телефонами
- ✅ **Перегляд** - дивіться всі телефони в одній таблиці
- ✏️ **Редагування** - змінюйте модель, ціни, статус
- 🗑️ **Видалення** - видаляйте записи безпечно
- ➕ **Додавання** - швидко додавайте нові телефони

### Аналітика
- 📊 **Dashboard** - вся статистика в одному місці
- 💹 **Прибутки** - відслідковуйте реальний та можливий прибуток
- 📈 **Статистика** - аналіз видатків та прибутків

### Фільтрація та пошук
- 🔍 **Розширений пошук** - по ID або моделі
- 🎯 **Множинне сортування** - 5 варіантів сортування
- ⚡ **Миттєві результати** - фільтри працюють в реальному часі

## 🌐 Дані

Проект використовує **MockAPI** для зберігання даних:
- Вся інформація синхронізується в хмарі
- Дані зберігаються і не втрачаються при перезавантаженні
- Можете отримати доступ до даних з будь-якого пристрою

API Base URL: `https://64870eb0beba6297278fcbfc.mockapi.io/Phonebook/`
